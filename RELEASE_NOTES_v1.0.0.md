# Türkiye Energy Intelligence Platform v1.0.0

First public research-software release of **EnerjiNabız AI**.

## Included

- Provider-independent demo and local-file execution
- Optional authenticated EPİAŞ adapter using documented electricity-service endpoints
- Public TEİAŞ report-catalog discovery adapter
- Reproducible data cleaning and data-quality reporting
- Consumption forecasting with seasonal-naive benchmark
- Multivariate anomaly detection
- CSV, Excel and optional Parquet exports for Power BI and Tableau
- Streamlit analytical dashboard and FastAPI read-only service
- Bilingual English/Turkish GitHub Pages website
- Citation metadata, Zenodo metadata, release validation and SEO files

## Data statement

The bundled dataset is synthetic and clearly marked. It exists so the software can be executed and reviewed without registration or credentials. Official EPİAŞ access is optional and requires each user's own account.

## Security statement

No credentials, private datasets or API secrets are included in this release.
