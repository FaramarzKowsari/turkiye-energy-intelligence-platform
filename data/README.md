# Data directories

- `samples/`: bundled synthetic input data, licensed CC0
- `raw/`: local/provider raw snapshots; keep sensitive or restricted files private
- `processed/`: normalized analytical tables generated by the pipeline
- `exports/`: Power BI/Tableau-ready fact, dimension and workbook outputs

Run `python scripts/generate_demo.py` and `python scripts/build_exports.py` to reproduce generated files.
