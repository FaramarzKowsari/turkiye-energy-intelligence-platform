# Data licensing and attribution

## Bundled synthetic data

The file `data/samples/energy_hourly_demo.csv` and all analytical outputs generated solely from it are dedicated to the public domain under **CC0 1.0**. They are synthetic and must not be represented as official Turkish electricity-market observations.

## External provider data

Data retrieved by optional connectors is not relicensed by this repository. Users are responsible for complying with the applicable terms, attribution requirements, access controls and redistribution rules of EPİAŞ, TEİAŞ or any other provider.

The recommended production pattern is to keep raw provider data in a private local or organizational storage layer and publish only analyses, models and derived indicators where permitted.
