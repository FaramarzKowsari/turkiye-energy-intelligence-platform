# Tableau integration

Use `data/exports/enerjinabiz_bi_pack.xlsx` or the CSV fact tables. The long-format `fact_generation_mix.csv` is optimized for stacked-area charts by generation source.

Suggested views:

- Hourly consumption and generation trend
- Weekday/hour heatmap
- Market price versus demand scatterplot
- Renewable share calendar
- Generation-mix stacked area
- Anomaly table with timestamp and score
